# Standard Docs

Standard documents at the project root and their purpose:

- `README.md` — the project front page: badges, quick start, screenshot when present.
- `LICENSE` — MIT or another license per need; follows the standard license format (hardwrapping allowed).
- `CONTRIBUTING.md` — contribution rules and the workflow that applies in this project.
- `CODE_OF_CONDUCT.md` — community code of conduct (Contributor Covenant).
- `SECURITY.md` — how to report security vulnerabilities and the response policy.
- `ARCHITECTURE.md` — the system blueprint: layers, data flow, key abstractions, entry points. Generated and kept up to date by Magic Context during dream sessions; track it but do not create it manually.
- `STRUCTURE.md` — the repository map: directory layout, directory purposes, and naming. Generated and kept up to date by Magic Context during dream sessions; track it but do not create it manually.

These files are created during Project Bootstrap, step 2, except `ARCHITECTURE.md` and `STRUCTURE.md`, which may not exist when a project is created — they appear after the first Magic Context dream session and are tracked once present. The AGENT updates them only when the architecture or structure changes significantly enough to render the recorded content inaccurate.
