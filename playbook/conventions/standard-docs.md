# Standard Docs

Standard documents at the project root and their purpose:

- `README.md` — the project front page: badges, quick start, screenshot when present.
- `LICENSE` — MIT or another license per need; follows the standard license format (hardwrapping allowed).
- `CONTRIBUTING.md` — contribution rules and the workflow that applies in this project.
- `CODE_OF_CONDUCT.md` — community code of conduct (Contributor Covenant).
- `SECURITY.md` — how to report security vulnerabilities and the response policy.

These files are created during Project Bootstrap, step 2.
